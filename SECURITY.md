# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/rethinkhealth/glion/security/advisories/new) or by email to <security@rethinkhealth.io>. Do not open a public issue or pull request for a security problem.

Include the affected package and version, a description of the problem, and steps to reproduce it. You will receive an acknowledgement within 5 business days.

## Supported versions

glion is under active development and has not reached 1.0. Fixes are released on the latest published version of each `@glion/*` package; older versions do not receive security patches.

## Disclosure

Once a fix is published, the advisory is made public through GitHub Security Advisories with credit to the reporter unless they ask otherwise.
